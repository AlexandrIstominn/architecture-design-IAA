# Работа выполнена

### Истомином Александром Алексеевичем

### РИС-22-2

# Тема ВКР:

# "Разработка приложения для выявления ботов в социальных медиа"


# Требования:

* пользователи могут анализировать свои списки подписчиков/друзей онлайн, чтобы выявлять подозрительные аккаунты;
* SMM-специалисты и администраторы сообществ могут загружать списки аккаунтов (через API соцсетей или файлы) и запускать массовый анализ;
* система рассчитывает «рейтинг бота» для каждого аккаунта и присваивает понятный статус (вероятно бот / подозрительно / вероятно человек);
* пользователи могут просматривать детализированную информацию, почему аккаунт признан ботом;
* результаты анализа доступны онлайн только авторизованным пользователям;
* поддерживается экспорт результатов (например, CSV/Excel/отчёт) для дальнейшей работы вне системы;
* предусмотрен REST API для интеграции с внешними системами (панели аналитики, CRM, внутренние инструменты компании).

# Дополнительный контекст:

* анализ может выполняться для нескольких социальных сетей с разными ограничениями и правилами использования API;
* на пике (во время рекламных кампаний или чистки аудиторий) возможен высокий трафик и массовые запросы на анализ десятков тысяч аккаунтов;
* ограниченные ресурсы на поддержку и эксплуатацию системы требуют максимально автоматизированных процессов и простой администрируемости.
